DNS Today

DNS remains a core Internet service. Websites, email, mobile apps, cloud services, and content delivery systems all use names to locate changing network resources.

What depends on DNS

  • Websites: address records direct visitors to web servers.
  • Email: MX records identify servers that receive mail.
  • Apps and cloud services: names help applications find services whose addresses can change.
  • Content delivery: DNS responses can guide users toward available or nearby servers.
  • Account security: TXT records can publish domain ownership and email policy information.

Security and privacy

Traditional DNS does not encrypt the request or cryptographically verify ordinary answers. DNSSEC adds signatures that let resolvers check whether signed DNS data is authentic and unchanged. It does not encrypt queries or certify that a website is safe.

DNS over TLS (DoT), DNS over HTTPS (DoH), and DNS over QUIC (DoQ) encrypt the connection between a device and its resolver. The resolver still sees the names being requested. QNAME minimization reduces the detail shared with intermediate servers during a lookup.

Risks to understand

  • Cache poisoning: false information is inserted into a resolver cache.
  • Hijacking: settings or records are changed to redirect users.
  • Amplification: open resolvers are misused to send large volumes of traffic to a target.
  • Outages: a mistaken record or configuration change can make a service difficult to reach.

DNSSEC protects the integrity of signed DNS data. Encrypted DNS protects the connection to a resolver. These features address different problems.
