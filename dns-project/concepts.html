Key DNS Concepts

These terms explain how DNS answers are found, how names are organized, and how answers are saved.

Domain name
A readable name, such as example.com, for a website or other Internet service.
Resolver
A service that looks up DNS information. A recursive resolver finds the answer for the device that asked.
Name server
A server that stores or provides DNS information. Authoritative name servers hold the official records for a zone.
Zone
A part of the DNS name system managed by a group of authoritative servers.
Delegation
When a parent zone points to the name servers that manage a smaller zone.
Resource record
A labeled piece of DNS data, such as an A record for an IPv4 address or an MX record for email.
Time to live (TTL)
How long a resolver can save a DNS answer before checking for it again.
