Key DNS Concepts

These concepts describe who answers a DNS question, how the namespace is divided, and how answers are reused.

Domain name
A readable name, such as example.com, used to identify a place or service on the Internet.
Resolver
Software that looks up DNS information for a client. A recursive resolver finds answers on the client’s behalf.
Name server
A server that stores or serves DNS information. Authoritative name servers provide the official records for a zone.
Zone
A portion of the DNS namespace managed by a set of authoritative servers.
Delegation
The process by which a parent zone points to name servers responsible for a child domain or zone.
Resource record
A typed piece of DNS data, such as an A record for IPv4 or an MX record for mail routing.
Time to live (TTL)
The period a resolver may keep a DNS answer in its cache before it needs to check again.
