DNS and why the web depends on it

The Domain Name System (DNS) turns names people can remember into information computers use to find websites, email, and other Internet services.

Explore how a lookup works →

Start with the essentials

DNS helps devices find the servers behind website and service names. Resolvers follow directions from one DNS server to another, then save answers for a while so they can respond faster next time.

Key terms

Domain name
A readable name, such as example.com.
Resolver
A service that looks up DNS answers for a device.
Resource record
A labeled piece of DNS information, such as a website address or mail server.
