DNS and why the web depends on it

DNS is a core part of the Internet. Websites, email, apps, cloud services, and more use it.

Explore how a lookup works →

Start with the essentials

When you enter a web address, DNS helps your device find the right server. DNS servers pass the question along and save answers for a while, which can speed up repeat visits.

Key terms

Domain name
A name people can read, such as example.com.
Resolver
A service that looks up DNS answers for a device.
Resource record
A piece of DNS information, such as a website address or mail server.
