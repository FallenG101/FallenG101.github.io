Origins of DNS

Before DNS, computers used host files: shared lists that matched names to addresses. As the Internet grew, keeping every copy up to date became hard.

The host file approach

  1. Organizations sent new computer names and addresses to a central registry.
  2. The registry published one master host file.
  3. Each computer downloaded a copy and updated it regularly.

Every computer relied on the same list. An old copy could point to the wrong address. Updating the list also got harder as more computers joined.

A distributed name system

In 1983, Paul Mockapetris described the first version of DNS. It split names into zones. Different organizations could manage their own zones, and resolvers could search across them to find answers.

The standards

RFC 1034 explains how DNS works. RFC 1035 describes how DNS software should handle records and messages. These standards set the foundation for DNS.

With DNS, new names could be added without sending a new full list to every computer.
