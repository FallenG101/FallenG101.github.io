Origins of DNS

Before DNS, networked computers relied on host files: centrally maintained lists mapping names to addresses. As the network grew, distributing and keeping every copy current became difficult.

The host file approach

  1. Organizations sent new host names and addresses to a central registry.
  2. A master host file was published.
  3. Each connected system downloaded a copy and had to refresh it regularly.

That approach made every machine depend on a shared list. A stale copy could point to an old address, and frequent updates became harder as more systems joined the Internet.

A distributed name system

In 1983, Paul Mockapetris described the first version of DNS. DNS divided the namespace into a hierarchy of zones. Each zone could be managed by a different organization, while resolvers could search across the hierarchy when they needed an answer.

The standards

RFC 1034 describes DNS concepts and facilities. RFC 1035 specifies implementation details, including resource records and DNS message formats. Together they established the core model used by DNS software.

Why the change mattered: DNS could grow without requiring every device to download a complete, centrally maintained list of Internet names.
